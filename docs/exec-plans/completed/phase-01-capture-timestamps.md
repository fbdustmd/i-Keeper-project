# Phase 1 캡처 시각 출력 — 2026-10-01

## 목표와 범위

Wireshark 대조용으로 패킷마다 실제 캡처 시각을 표시한다. 패킷 본문과 파서는 추가하지 않는다.

## 설계와 완료 기록

- [x] pcap_pkthdr.ts의 초·마이크로초를 UTC ISO 8601 형식으로 변환한다.
- [x] Z와 소수점 6자리로 시간대·표시 단위를 분명히 한다.
- [x] 음수 초, 유효 범위 밖 마이크로초, 날짜 변환 실패를 오류 처리한다.
- [x] 기존 길이 출력 뒤에 캡처 시각을 추가한다. 수·시간·Ctrl+C 종료는 유지한다.
- [x] 고정 시각 기반 모의 테스트와 잘못된 시각의 정리 경로를 검증한다.
- [x] 엄격 빌드·CLI 17개·모의 시나리오 15개·실제 loopback 캡처 시각과 종료 회귀 검증 통과.
- [x] 사용자 설명서에 Wireshark 대조 절차를 기록한다.

실시간 패킷 5개의 시각을 실제 실행 구간과 비교했다.
소수점 표시 자릿수는 측정 정확도 보장이 아니다. 실제 Wireshark 동시 대조는 미검증이다.

## 후속 변경 — 2026-10-01

사용자가 Wireshark 한글 UI와 읽기 쉬운 동일 표시 형식을 요청했다.
기본 출력을 PC 현지 `YYYY-MM-DD HH:mm:ss.ffffff`로 변경하고 UTC T/Z를 제거했다.
원래 캡처 시각 값은 보존한다. 메뉴명은 공식 한국어 번역에서 확인했고 USER_GUIDE를 갱신했다.
고정 시각·실시간 시각·기존 CLI와 종료 테스트가 모두 통과했다.
별도 Wireshark 동시 캡처의 측정값 완전 일치는 검증하거나 보장하지 않는다.
